# ARCHIVUM — Personal Study Museum

Android向けPWAのスターターです。暖色の博物館・マホガニー調UI、教科/単元管理、学習タスク、暗記カード、確認テスト、間違い問題保管庫、ストップウォッチ、カレンダー計画、教科別メモ検索、JSONバックアップを含みます。

## 重要：クラウド同期を有効にする

このパッケージ単体ではクラウドアカウントやホスティングは作成されません。以下の設定が必要です。

1. Supabaseでプロジェクトを作成
2. SQL Editorで `supabase-schema.sql` を実行
3. Project Settings → APIからProject URLとanon/publishable keyを取得
4. このアプリをHTTPS対応の静的ホスティングに配置
5. アプリの「クラウド接続設定」からURL、anon key、メール、パスワードを入力して新規登録/ログイン

anon keyはブラウザ公開用キーです。service_role keyは絶対に入力・公開しないでください。RLSポリシーにより各ユーザーは自分の行だけを読み書きします。

## Androidホーム画面への追加

HTTPSで公開したURLをChromeで開き、右上の︙ →「ホーム画面に追加」または「アプリをインストール」を選びます。manifestとservice workerを使用します。PWAのインストール可否はブラウザ/ホスティング条件に依存します。

## 公開方法の例

GitHub Pages、Cloudflare Pages、Netlifyなどの静的ホスティングへフォルダ内ファイルを配置してください。HTTPSが必要です。`file://` から直接開く方法ではPWA機能は動きません。

## 現在の実装範囲と注意

- ローカル端末への保存とJSONバックアップ/復元
- Supabaseログインとユーザー単位のJSONデータ同期（初期版）
- 教科別単元一括登録、タスク、カード、試験、計画、メモ、クイズ、誤答記録、ストップウォッチ
- クイズ形式：単一選択、複数選択、記述、画像URL
- 削除は項目メニューから確認後に実行（長押しでも確認を表示）

この初期版は同期の競合解決、複数端末での同時編集マージ、画像ファイルのクラウドアップロード、完全なページ内リンク検索、タイマーのバックグラウンド精度保証は未実装です。クラウド同期を有効化する前に、必ずバックアップを作成してください。
